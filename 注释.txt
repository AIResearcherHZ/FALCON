──── 步骤1  训练
# 复制即跑(后台 tmux,断 SSH 不挂):默认 TensorBoard,不用登 wandb;选卡在 g1 后加 CUDA_VISIBLE_DEVICES=0;显存紧再追加 num_envs=2048(本机12G)
# 多卡训练: 复制即跑的完整命令见上方「训练加速」节 B(G1,4 卡);首次上服务器先按节 A 验证两步
(1) ./run_train.sh g1 python humanoidverse/train_agent.py \
      +exp=decoupled_locomotion_stand_height_waist_wbc_diff_force_ma_ppo_ma_env \
      +simulator=isaacgym \
      +domain_rand=domain_rand_rl_gym \
      +rewards=dec_loco/reward_dec_loco_stand_height_ma_diff_force \
      +robot=g1/g1_29dof_waist_fakehand \
      +terrain=terrain_locomotion_plane \
      +obs=dec_loco/g1_29dof_obs_diff_force_history_wolinvel_ma \
      project_name=g1_29dof_falcon \
      experiment_name=g1_29dof_falcon \
      obs.add_noise=True \
      robot.dof_effort_limit_scale=0.9 \
      rewards.reward_initial_penalty_scale=0.1 \
      rewards.reward_penalty_degree=0.0001

    # ── 各行含义(\ 是续行,整段可直接复制;以下注释别跟到命令里)──
    #  +exp=...                 实验总配方:解耦上下身 WBC + 力控 + PPO(最关键的总开关)
    #  +simulator=isaacgym      仿真器(可换 isaacsim / genesis / mujoco)
    #  +domain_rand=...         域随机化:随机摩擦/质量/延迟等,利于真机迁移
    #  +rewards=...             奖励配方(站立高度 + 行走 + 力控)
    #  +robot=g1_29dof_...      本体:Unitree G1 29 自由度 + 假手
    #  +terrain=...plane        地形:平地
    #  +obs=...                 观测配方(带历史、含末端力、不含线速度)
    #  project_name / experiment_name   日志目录命名:logs/<项目>/<时间戳-实验名-...>
    #  ↓↓ 以下 4 行是 FALCON 官方 G1 配方,均改了配置默认值,删了会偏离论文 ↓↓
    #  obs.add_noise=True                      观测加噪(默认 False)→ 抗噪、利于 sim2real
    #  robot.dof_effort_limit_scale=0.9        关节力矩上限 ×0.9(默认 0.8)→ 放宽出力
    #  rewards.reward_initial_penalty_scale=0.1  惩罚课程初始权重(默认 0.5)→ 早期惩罚更轻,先学会动
    #  rewards.reward_penalty_degree=0.0001      惩罚权重每步增速(默认 1e-5)→ 课程收紧快 10 倍
    #  日志: TensorBoard 默认自动开,写在 logs/g1_29dof_falcon/<run>/ ;看图见本节(4)
    #  想用 wandb: 末尾追加  +opt=wandb wandb.wandb_entity=<你的wandb账号>  (默认账号是作者的,不改会登录失败)
(2) 看进度: tmux attach -t g1 (脱离 Ctrl-b d) | 跟日志: tail -f logs/launch/g1_*.log | 停: tmux kill-session -t g1
    # 想前台直接看(不进 tmux): 把 (1) 开头的 ./run_train.sh g1 删掉,直接 python humanoidverse/train_agent.py ...
(3) 续训: 末尾加 +checkpoint=logs/g1_29dof_falcon/<run>/model_<iter>.pt
(4) TensorBoard: tensorboard --logdir logs --host 0.0.0.0 --port 6006

──── 步骤2  评估 (自动开 viewer,1 env;会自动读 ckpt 同目录的训练配置,无需重复传参)
(1) 复制即跑(自动选最新 checkpoint):
    python humanoidverse/eval_agent.py \
      +checkpoint=$(ls -t logs/g1_29dof_falcon/*/model_*.pt | head -1)
    # 想看指定某个: 把上面一行换成  +checkpoint=logs/g1_29dof_falcon/<run>/model_<iter>.pt

──── 步骤3  Sim2Sim (MuJoCo,在 sim2real/ 下,conda fcreal,开两个终端)
(1) 终端1: cd sim2real && python sim_env/loco_manip.py \
      --config=config/g1/g1_29dof_falcon.yaml
(2) 终端2: cd sim2real && python rl_policy/loco_manip/loco_manip.py \
      --config=config/g1/g1_29dof_falcon.yaml \
      --model_path=models/falcon/g1_29dof.onnx
    # 键盘: ] 启动  o 急停  = 站/走切换  wsad 速度  qe 偏航  z 零速  12 base高

──── 步骤4  真机 (Unitree G1)

──── 可选参数 (追加在命令末尾, 务必带 +)
  +motion_idx=10     从第几个动作开始播放
  +speed=0.5         播放倍速 (<1 慢放, >1 快放)
  +loop=False        当前动作播完不循环, 自动切下一个
  +max_motions=20    只加载前 N 个动作 (pkl 动作多, 调小可加快启动)
  +scene_xml=...     手动指定 MuJoCo 场景 xml (默认自动匹配 freebase 场景)

──── 键盘控制 (viewer 窗口内)
  空格 暂停/播放    n 下一个    p 上一个    r 重播当前
